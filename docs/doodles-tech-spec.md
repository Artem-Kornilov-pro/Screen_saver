# Дудлы СберKids — техническое описание

Трек A «Приколы». Календарные эффекты поверх главного экрана; контент управляется JSON на CDN.

## 0. Ограничения из ТЗ

| Требование | Как закрываем |
|---|---|
| Слой поверх, не блокирует сценарии | Оверлей не перехватывает касания, эффект ≤ 4 с |
| Не замедлять запуск | Ничего на пути холодного старта; загрузка после отрисовки главного экрана |
| Вес ≤ 6 МБ, кэш на устройстве | Лимит кэша 6 МБ, LRU, предзагрузка на окно в N дней |
| Без бэкенда | Только статика на CDN |
| Управляемость контентом | Новые дата/эффект — правка JSON + ассеты, без релиза |
| Новые зависимости дорого, на iOS запрещены | Нативные рендереры на Compose Canvas / SwiftUI Canvas, без сторонних библиотек |
| Персональные данные не уходят с устройства | Дата рождения, возраст, альбом — только локально |
| Слабые телефоны | Лимиты на частицы и длительность, остановка таймеров, reduced motion |

## 1. Календарь (контент)

### 1.1. Модель записи

```json
{
  "id": "cosmonautics",
  "when": { "type": "fixed", "md": "04-12" },
  "priority": 50,
  "age": { "min": 6, "max": 13 },
  "minAppVersion": "5.12.0",
  "effect": { "...": "см. раздел 2" },
  "fact": "Первым в космос полетел Юрий Гагарин. Полёт длился 108 минут.",
  "share": { "template": "postcard_space", "title": "Я нашёл кота-космонавта!" },
  "enabled": true
}
```

### 1.2. Правила дат (`when.type`)

| Тип | Параметры | Пример |
|---|---|---|
| `fixed` | `md` | `{"type":"fixed","md":"03-01"}` |
| `range` | `from`, `to` (через Новый год тоже работает) | `{"type":"range","from":"12-25","to":"01-08"}` |
| `nth_weekday` | `month`, `weekday` (1=пн), `n` (−1 = последний) | 2-й вторник февраля: `{"month":2,"weekday":2,"n":2}` |
| `dates` | `list` — явные даты для плавающих праздников | Масленица, вносится на каждый год вручную |
| `birthday` | — | Дата берётся из локального профиля, наружу не уходит |

- Дату считаем по локальному часовому поясу устройства, граница — 00:00.
- Если на день подходят несколько записей, берём ту, у которой больше `priority`. `birthday` всегда в приоритете.
- Фильтры: `age`, `minAppVersion`, `platforms`, поддерживается ли тип эффекта клиентом. Неизвестный тип пропускаем молча.

### 1.3. Стартовый набор дат (черновик)

| Дата | Повод | Эффект | Тема факта |
|---|---|---|---|
| 01-01 | Новый год | снег + шапка на СберКоте | — |
| 2-й вт февраля | День безопасного интернета | щит-стикер на карте | «Не говори код из СМС» |
| 03-01 | День кошек (РФ) | лапки по экрану | — |
| 03-08 | 8 Марта | цветы-частицы | — |
| 03-14 | День числа π | цифры π падают | π ≈ 3,14 |
| 03-31 | День рождения Чуковского | стикер Мухи-Цокотухи | монетка, самовар → покупка |
| 04-01 | День смеха | кот «переворачивает» аватар | — |
| 04-12 | День космонавтики | ракета через экран, кот в шлеме | Гагарин, 108 минут |
| 04-22 | День Земли | листья | экономить ресурсы |
| 05-15 | День семьи | сердечки | — |
| 06-01 | День защиты детей | конфетти | — |
| 06-06 | День русского языка | буквы-частицы | — |
| 07-08 | День семьи, любви и верности | ромашки | — |
| 08-08 | Всемирный день кошек | кот машет лапой | — |
| 09-01 | День знаний | колокольчик + звёзды | планировать карманные деньги |
| 10-04 | День животных | следы зверей | — |
| 10-05 | День учителя | мел на «доске» | — |
| 10-31 | Всемирный день сбережений | монетки падают в копилку | копить vs тратить |
| посл. вс ноября | День матери | сердечки | — |
| birthday | День рождения ребёнка | торт + конфетти | — |

Итого 30–50 записей. Каждый факт — одна фраза для младших (они читают по слогам). Чувствительные даты (военные, религиозные) обходим или согласовываем с редакцией. Возрастная маркировка контента — 0+/6+ (436-ФЗ).

## 2. Эффекты (шаблоны)

### 2.1. Типы рендереров

Каждый тип — код в приложении, контент — параметры в JSON. Новый тип требует релиза, новая дата — нет.

| `type` | Что делает | Параметры |
|---|---|---|
| `particles` | Частицы падают или разлетаются из точки | `sprites[]`, `count` (≤ 60), `gravity`, `spread`, `origin`, `durationMs` |
| `sticker` | Стикер выпрыгивает у якоря и исчезает | `image`, `anchor`, `anim` (`pop`/`bounce`/`fly`), `durationMs` |
| `skin` | Временный аксессуар на элементе (шапка на СберКоте, рамка на аватаре) | `anchor`, `image`, `offset`, `ttl` (до конца дня) |
| `ptr` | Своя анимация pull-to-refresh | `frames` (спрайт-лист) или `lottie` (на Android, если Lottie уже есть в сборке) |
| `combo` | Последовательность эффектов | `steps[]` |
| `web` *(опционально)* | HTML-бандл в прозрачном WebView | `bundle`, `sha256` — новые механики без релиза |

### 2.2. Триггеры

Эффект запускает пользователь. Дудл заметен, но не навязчив: на якоре висит маленький индикатор, например искорка на СберКоте. Скрытый в неочевидном месте эффект — антипример из ТЗ.

| `trigger` | Реализация |
|---|---|
| `tap` | Тап по якорю (`cat`, `avatar`, `card`, `tabbar.home`) |
| `shake` | Android — `SensorManager` (акселерометр); iOS — `CoreMotion` / `motionEnded` |
| `pull` | Событие pull-to-refresh |
| `longpress` | Долгое нажатие на якорь |
| `combo` | Лестница из трёх уровней: тап → `taps` быстрых тапов → `finale` (`shake` / `pull`) → `effect`. Стиль растёт: каракуля → наклейка → неон |

### 2.3. Пример блока `effect`

```json
"effect": {
  "type": "combo",
  "trigger": "tap",
  "anchor": "cat",
  "hint": { "type": "sparkle", "anchor": "cat" },
  "steps": [
    { "type": "skin", "image": "helmet.webp", "anchor": "cat", "ttl": "day" },
    { "type": "particles", "sprites": ["star1.webp", "star2.webp"], "count": 40, "durationMs": 2500 }
  ],
  "variants": [
    { "weight": 80, "override": {} },
    { "weight": 20, "override": { "steps.1.sprites": ["rocket.webp"] } }
  ],
  "combo": { "taps": 3, "windowMs": 2500, "finale": "shake", "effect": { "type": "sticker", "image": "alien.webp", "anim": "fly" } }
}
```

### 2.4. Бюджеты рендера

- Длительность ≤ 4 с; ввод не блокируется ни на кадр.
- Частиц ≤ 60; спрайты ≤ 128×128, WebP; никаких картинок больше экрана и видеослоёв.
- Один `Canvas` на оверлей, без отдельного view на каждую частицу.
- Таймеры и анимации останавливаются по окончании эффекта и на `onPause` / смене `scenePhase`.
- Reduced motion (Android: animator duration scale = 0; iOS: `UIAccessibility.isReduceMotionEnabled`) → статичный стикер вместо анимации.
- Касания проходят сквозь оверлей: iOS — `isUserInteractionEnabled = false` / `.allowsHitTesting(false)`; Compose — оверлей без `pointerInput`.

### 2.5. Тип `web` (если берём)

- WKWebView / Android WebView, прозрачный фон, создаётся лениво по триггеру и уничтожается после эффекта.
- Бандл с CDN проверяется по `sha256` из манифеста до запуска.
- Сеть внутри бандла запрещена (CSP `default-src 'self'`); связь с приложением — только `postMessage` с белым списком событий (`FINISH_EVENT`, `VIBRATION_EVENT`, `SHARING_EVENT`).
- Минус: исполняемый код с CDN потребует согласования с безопасностью. Для MVP достаточно нативных типов.

## 3. Архитектура

### 3.1. Структура CDN

```
/doodles/v1/manifest.json          # маленький, с ETag
/doodles/v1/packs/<id>/<file>      # ассеты дудла
```

```json
{
  "schema": 1,
  "enabled": true,
  "generatedAt": "2026-09-20T10:00:00Z",
  "prefetchDays": 5,
  "items": [ { "id": "cosmonautics", "...": "...", "pack": { "size": 184320, "files": [ { "path": "helmet.webp", "sha256": "..." } ] } } ]
}
```

### 3.2. Поток на клиенте

1. **Холодный старт** — дудлы не трогаем вообще.
2. **Главный экран отрисован → idle**: фоновый `GET manifest.json` с `If-None-Match`.
3. **Предзагрузка**: паки на `[сегодня … сегодня + prefetchDays]`, проверка `sha256`, атомарная запись в кэш.
4. **Кэш**: лимит 6 МБ, LRU, просроченные паки удаляем.
5. **Выбор**: локальная дата → фильтры → `priority` → один дудл на день.
6. **Пак не скачан или манифест недоступен** → ничего не показываем, без спиннеров и ошибок.
7. **Триггер** → рендер → по окончании оверлей снимается, ресурсы освобождаются.

### 3.3. Управление без релиза

- Kill switch: `enabled: false` глобально или на конкретной записи.
- `schema` — версия формата; клиент игнорирует то, чего не понимает.
- `minAppVersion` — эффекты, которым нужен новый рендерер.
- Отладка: в debug-сборке подмена даты и URL манифеста.

### 3.4. Платформы

| | Android | iOS |
|---|---|---|
| UI оверлея | Jetpack Compose `Canvas` + `withFrameNanos` | SwiftUI `Canvas` + `TimelineView` (iOS 15+) |
| Сеть / кэш | существующий HTTP-клиент + файловый кэш | `URLSession` + `FileManager` |
| Локальное состояние | DataStore | `UserDefaults` / файл |
| Тряска | `SensorManager` | `CoreMotion` |
| Шаринг | `Intent.ACTION_SEND` + `FileProvider` | `UIActivityViewController` |

Сторонних зависимостей нет.

## 4. Виральность (техническая часть)

### 4.1. Открытка «поделиться»

- Генерируется локально: шаблон (фон из пака) + заголовок + дата + картинка эффекта → PNG ~1080×1350.
- Без имени и других персональных данных.
- Отправка через нативный share sheet (в WebView-прототипе — `SHARING_EVENT`).
- Шаблоны и тексты лежат в паке, их меняют без релиза.

### 4.2. Альбом дудлов

- Локальный список `{ id, year, foundAt }`, никуда не отправляется.
- Пропущенные дни показываются как «вернётся в следующем году», без серого «упустил».
- Счётчик «найдено N из M за год» — для 8–10 лет (коллекционирование).

### 4.3. Повторяемость

- `variants` с весами — каждый запуск немного разный.
- `combo` — чем сложнее жест, тем больше эффектов; шкала и пиктограмма жеста подсказывают следующий шаг без текста.

### 4.4. Без тёмных паттернов

- Нет серий, которые сгорают, нет таймеров «осталось 2 часа», нет пушей «ты пропустил дудл».
- Нет наград с денежной ценностью и привязки к тратам.

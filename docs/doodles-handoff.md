# Handoff: дудлы СберKids

Прототип: [web/index.html](../web/index.html) (экран + отладка, раздел «Дудлы»), [web/gallery.html](../web/gallery.html) (все дудлы). Источник правды по контенту — [web/effects/doodles/manifest.json](../web/effects/doodles/manifest.json). Движок — [web/js/doodles.js](../web/js/doodles.js). Как дудлы уживаются с праздничным слоем, описано в [README](../README.md).

## Overview

Дудл — маленький праздник поверх главного экрана. В особые дни на элементе интерфейса появляется подсказка; ребёнок сам запускает эффект и видит сцену на 2–4 секунды и аксессуар на коте до конца дня. Дальше — комбо из трёх уровней (раздел «Комбо»). Аудитория — 10–13 лет, текстов в приложении нет: факты остались в манифесте, но плашка выключена.

Принципы, из которых выведены все решения ниже:

1. **Слой, а не экран.** Ничего не блокирует: касания проходят сквозь эффект, никаких модалок, спиннеров и ожиданий.
2. **Запускает ребёнок.** Автоматически показывается только подсказка (и аксессуар с флагом `auto`). Сцена — только по действию.
3. **Кто не нашёл — ничего не потерял.** Нет серий, таймеров, пушей и «упущенного».
4. **Контент без релиза.** Новая дата = запись в JSON + папка с SVG. Новый тип траектории = релиз.
5. **Учит между делом.** Каждый дудл несёт одну фразу: финграмотность, безопасность или мягкие навыки.

## Комбо: тап → 3 тапа → финальный жест

Аудитория — 10–13 лет. Текстов в приложении нет, всё объясняет визуал. Один тап даёт сцену, а кто разобрался в комбинации, получает больше: так дети пересказывают друг другу «а ты знаешь, как открыть ежа?».

| Уровень | Жест | Что происходит | Стиль |
|---|---|---|---|
| 1 | тап по якорю (или жест из `trigger`) | базовая сцена дудла, аксессуар на аватар | **каракуля**: кремовая обводка, линия «дрожит» (3 кадра на частицу, SVG-фильтр на стикерах) |
| 2 | ещё `combo.taps` (3) быстрых тапа за `combo.windowMs` (2,5 с) | сцена ещё раз, частиц ×1,4, всплеск из якоря | **наклейка**: толстая белая обводка и тень |
| 3 | `combo.finale`: `shake` или `pull` | `combo.effect` (ёж, подарок, НЛО…), неоновая вспышка-кольцо из якоря, два неоновых всплеска | **неон**: цветное свечение |

- После первого уровня рядом с якорем появляется шкала ●○○ и пиктограмма следующего жеста: палец стучит три раза, стрелка «потяни вниз» или телефон трясётся. Шкала встаёт с той стороны якоря, где есть место.
- Каждый тап на уровнях 1–2 даёт отклик: якорь пружинит, из него вылетает пара частиц, вторая точка шкалы заполняется по третям.
- Не тот жест — пиктограмма нужного жеста подпрыгивает. Тап на уровне 2 тоже подталкивает к финалу.
- Без действий 7 с комбо сбрасывается. Через 3,2 с после финала его можно пройти снова.
- Тряска, которую дудл «съел» на любом уровне, не уходит праздничному слою.
- Стили частиц рисуются один раз на картинку и размер (силуэт, обводка, свечение на canvas), без фильтров в кадре. На стикерах — CSS `drop-shadow` и один SVG-фильтр для «дрожания».

## Animation / Motion

**Как устроена плавность.** Каждая траектория — функция состояния от `t ∈ [0..1]` (позиция, поворот, масштаб `sx/sy`, прозрачность). Движок сэмплирует её в 48–96 кадров и отдаёт в WAAPI с `easing: linear`: между соседними кадрами интерполяция линейная, но кадров так много, что движение идёт по гладкой кривой, без «углов» на опорных точках. Ускорение и замедление зашиты в саму функцию, а не в CSS-easing. В нативе та же функция кладётся в `Animatable` / `TimelineView`.

**Общие кривые:**
- `spring(t) = 1 − e^(−6t)·cos(10t)` — пружина с перелётом ~15 % (аксессуары, `pop`, плашка факта);
- `inOutSine`, `outCubic`, `inQuad`, `outBack`, `smoothstep` — для разгонов, торможений и затуханий;
- наклон по курсу — угол касательной к траектории (`heading`), чтобы ракета и лыжник смотрели туда, куда летят.

| Траектория | Где | Длительность | Кадров | Описание |
|---|---|---|---|---|
| `fly` | ракета | 1800 мс | 60 | кубическая Безье из левого нижнего угла в правый верхний; разгон `0.3t + 0.7t²`; нос по касательной + дрожь ±1,5° |
| `ski` | снеговик | 3000 мс | 72 | склон с кочками `max(0, sin(4πk))·16 px`; разгон `0.55t + 0.45t²`; наклон по касательной, −12…32° |
| `float` | зонтик | 3400 мс | 72 | маятник `sin(3πt)·22 % W`, наклон `cos(3πt)·16°` — как падающий лист |
| `drift` | НЛО, змей | 2600–3000 мс | 60 | горизонтально, волна ±16 px, крен ±8° |
| `walk` | ёжик, пингвин, краб | 2600–3600 мс | 84 | 7 шагов: подпрыгивание 5 px, покачивание ±4°, сжатие 4 % на касании |
| `sail` | кораблик | 4200 мс | 72 | ровный ход, волна ±5 px, качка ±7° |
| `bounce` | мяч, лягушка | 2800–3200 мс | 96 | 4 параболы, высота × 0.68 на прыжок; сжатие при касании `sx 1.14 / sy 0.8`; 600° вращения |

**Частицы:**
- взрыв из точки (`origin: anchor/at`) тормозится воздухом: `v /= 1 + drag·dt`, по умолчанию `drag = 1.6`, стартовая скорость × 1.35;
- дождь сверху/снизу идёт волной: у каждой частицы задержка старта 0…35 % жизни, а не залп в один кадр;
- появление — масштаб 0.35 → 1 по `outBack` за первые 14 % жизни; затухание — `smoothstep` последние 38 %;
- покачивание `sway` — синус со своей частотой 1,8–2,8 Гц у каждой частицы + наклон по фазе;
- спрайты растеризуются в bitmap один раз под максимальный размер (шаг 16 px × DPR), а не рисуются из SVG каждый кадр.

## Content rules

- **Факт:** ≤ 110 символов, 1–2 предложения, слова из словаря 6–9 лет, без канцелярита. Цифры — только проверяемые (50 ₽ × 52 = 2 600 ₽, 10 ₽ × 365 = 3 650 ₽).
- **Открытка (`share`):** ≤ 50 символов, от первого лица ребёнка, без имени и других персональных данных.
- **Иллюстрации — без текста.** Текст не масштабируется, не переводится и не читается младшими.
- **Возраст 0+/6+** (436-ФЗ). Без страшного (клоуны, монстры), без военной и религиозной тематики, без брендов.
- **Пак** ≤ 50 КБ на дудл (сейчас 3–11 КБ), весь кэш ≤ 6 МБ.

## Art direction

Вдохновлено визуальным языком СберKids: тёмный фон, сочные цвета, мягкие «игрушечные» объёмы. Персонажи и брендинг не заимствуются.

**Объём (soft 3D):**
- Основная заливка — градиент от светлого тона (блик, сверху слева) к тёмному (тень, снизу справа): `radialGradient` с центром 36–40 % / 30–35 % для круглых форм, `linearGradient` по диагонали — для плоских.
- Один-два блика: белые эллипсы 45–90 % непрозрачности, повёрнутые по форме.
- Тень от формы — полупрозрачная заливка того же тона, темнее на 30–40 % (12–25 %), на теневой стороне.
- Персонажи стоят на мягкой тени: эллипс `#000` 20–22 %.
- Стикеры в слое получают `drop-shadow(0 6px 10px rgba(0,0,0,.35))`, чтобы отделяться от интерфейса.
- Светящиеся объекты (лампочки, огни НЛО, шлема) — круг того же цвета 22–25 % вокруг.

**Форма:**
- Скруглённые углы и концы: `stroke-linejoin/linecap: round`. Острые многоугольники (клён, звезда, иголки ёжика) скругляются обводкой той же заливки 2,6–3 px.
- Контур `#212529` — только на мелких деталях (зрачки, оправа). Крупные формы без обводки.
- Тёмные детали на тёмном фоне получают светлый ореол: обводка `#F8F9FA` 35–40 % под основным штрихом (очки 1 апреля), либо осветляются до `#ADB5BD` (палки, ручка зонтика).

**Технические правила SVG:**
- Градиент только на заливках и замкнутых фигурах. На прямой линии (у bbox нулевая ширина или высота) градиент с `objectBoundingBox` не рисуется — снежинки рисуем двумя сплошными штрихами: широкий полупрозрачный голубой + узкий светлый.
- Без фильтров внутри SVG (`feGaussianBlur` и т. п.) — дорого на слабых телефонах; тени и свечения — полупрозрачными фигурами.
- Без текста и шрифтов. Анимация внутри SVG — только SMIL на мелочах (лампочки, зрачки).
- Вес: 0,6–4 КБ на картинку, все 9 паков — 66 КБ.

**Палитра:** яркие open-color тона (`#FA5252`, `#339AF0`, `#FCC419`, `#51CF66`, `#F783AC`, `#9775FA`) + фирменный зелёный `#21C25E` акцентом. Для каждого цвета — тройка «блик / основной / тень», например красный `#FFC9C9 / #FA5252 / #A61E1E`.

**СберКот:** не перерисовываем. Аксессуары рассчитаны под существующий аватар: ширина = ширина аватара × `scale`, центр совпадает с центром аватара, `dx/dy` — сдвиг в долях ширины.

## Edge cases

- **Два дудла на один день** — выигрывает больший `priority`, день рождения выше всех.
- **Полночь при открытом приложении** — дата пересчитывается при возврате из фона (в прототипе — при перезагрузке).
- **Якорь отсутствует** (A/B-вариант экрана без «Копилок») — дудл не запускается целиком, без частичных эффектов.
- **Экран проскроллен** — подсказка и аксессуар уезжают вместе с аватаром; `pull` работает только наверху списка. Плашка факта в прототипе привязана к аватару — в приложении, если аватар вне вьюпорта, ставить её под статус-бар.
- **Быстрые тапы** — считаются в комбо, каждый даёт отклик; частиц на экране не больше 80.
- **Слабое устройство** — DPR canvas ≤ 2, спрайты ≤ 128 px, нет видео и фоновых анимаций; при `visibilitychange` всё останавливается.
- **Нет сети** — работаем с кэшем паков, который скачан заранее (окно `prefetchDays`); нет пака — нет дудла, без ошибок.
- **Широкие экраны** — `fullWidth`-стикеры масштабируются по ширине, остальные — фиксированного размера.

## Accessibility

- Слой эффектов скрыт от скринридера (`aria-hidden="true"` / `importantForAccessibility="no"`); подписи элементов (аватар «Профиль») не меняются.
- Факт озвучивается один раз через live-регион (`aria-live="polite"`; iOS — `UIAccessibility.post(.announcement)`).
- Никакое действие не доступно только через дудл: это бонус, а не функция.
- Reduced motion (`prefers-reduced-motion`, Android animator scale = 0, iOS Reduce Motion) — без частиц и полётов.
- Мигание гирлянды ~0,8 Гц — ниже порога 3 вспышек в секунду (WCAG 2.3.1).
- Вибрация — 15 мс, только после пользовательского жеста. Как и праздничный слой, дудл просит её у приложения сообщением `VIBRATION_EVENT`.

## Перенос в нативное приложение

| | Android (Compose) | iOS (SwiftUI) |
|---|---|---|
| Слой | `Box` поверх экрана без `pointerInput` | `ZStack` + `.allowsHitTesting(false)` |
| Частицы | `Canvas` + `withFrameNanos` | `Canvas` + `TimelineView(.animation)` |
| Стикеры | `Animatable` по ключевым кадрам из той же формулы траектории | `KeyframeAnimator` (iOS 17) / `withAnimation` по шагам (iOS 15) |
| SVG | конвертировать паки в WebP на CDN или VectorDrawable | WebP/PDF; сторонние SVG-библиотеки на iOS запрещены |
| Якоря | `Modifier.onGloballyPositioned` → реестр якорей | `anchorPreference` → реестр якорей |

Траектории задаются формулами от `W, H, w, h, from, to` — их можно перенести один в один, а JSON-манифест остаётся общим для обеих платформ.

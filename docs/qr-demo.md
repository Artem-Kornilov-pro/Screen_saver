# QR-приколюхи — локальное демо

## Запуск

Из корня проекта:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory web
```

Открыть `http://127.0.0.1:8765/?qr=detective`.
Обычный главный экран остаётся по `/`, плитка QR открывает сканер.

Сюжеты в параметре `qr`: `detective`, `fishing`, `magic`, `rocket`, `chase`.
На телефоне сюжет выбирается под рамкой, на компьютере — также в панели справа.
Форма рамки выбирается отдельно: вверху сканера или в блоке «Рамка сканера»
панели справа. Варианты: обычная, лупа, портал, иллюминатор и которамка.
Выбор совместим со всеми пятью сюжетами и тремя стилями, сохраняется при смене
сюжета и повторе сканирования. Смена рамки не сбрасывает текущий результат.
Для открытия с выбранной рамкой добавьте `&frame=loupe`, `portal`, `porthole`
или `cat` к ссылке `/?qr=detective`. Все рамки — собственные SVG с прозрачной
центральной областью; стандартные уголки заменяются, а не рисуются поверх.
Кнопка «Поймать демо-код» запускает событие распознавания без камеры.
«Сканировать ещё» возвращает поиск. На компьютере доступны повтор, проверка
ошибки, три стиля дудла, уменьшение движения и необязательный звук.

## HTTPS для телефона

Если установлен инструмент разработки cloudflared, при запущенном сервере:

```sh
cloudflared tunnel --url http://127.0.0.1:8765
```

Открыть выданный HTTPS-адрес с `/?qr=detective`.
Это временный публичный туннель только к папке `web/`, без доступа к Git
и остальному рабочему каталогу. Остановка туннеля отключает ссылку.
Cloudflared не входит в приложение и не нужен для работы его кода.

Для демо без камеры можно запустить сервер с `--bind 0.0.0.0` и открыть
`http://<локальный-IP-Mac>:8765/?qr=detective` в той же Wi-Fi сети.
HTTP по локальному IP не даёт доступа к камере на телефоне.

## Что добавлено

- Кот-детектив: лапа с лупой ищет QR, увеличение демо-кода, довольный кивок.
- Рыбалка: поплавок и круги на воде, нырок, рыбка с галочкой.
- Магия: палочка, сбор искр к коду и короткая вспышка.
- Ракета: поисковый полёт, запуск, дым и небольшое покачивание фона.
- Догонялки: мышка прячется, кот подкрадывается и подпрыгивает при поимке.

Графика продолжает существующие SVG-паки: объём через градиенты и блики,
мягкие формы, белая обводка наклейки или неоновая подсветка. Ракета и частицы
взяты из текущих паков; кот — самостоятельный новый персонаж, без Сберкота
и узнаваемых персонажей сторонних брендов.

Три варианта оформления повторяют язык дудлов: каракуля, наклейка, неон.
Уменьшение движения учитывает и системный `prefers-reduced-motion`, и настройку демо.

## Реальное распознавание и ограничения

Нет сторонних библиотек, декодеров, шрифтов, CDN или внешних API.
Собственные HTML/CSS/JS, SVG и Web Audio API. Камера подключается по нажатию.

Реальные QR считываются **только встроенным `BarcodeDetector`** при наличии
поддержки формата `qr_code` и HTTPS/localhost. Поддержка определяется в момент
нажатия. В браузере без этого API (в частности, во многих версиях Safari)
отображается понятное сообщение и остаётся полностью рабочее анимационное демо.
HTTPS позволяет запросить камеру, но не добавляет отсутствующий QR-детектор.

Сканируется область рамки с учётом `object-fit: cover`. Кадры обрабатываются
на устройстве. Камера освобождается после распознавания, закрытия и ухода в фон.
Учтён поздний ответ на запрос разрешения после закрытия экрана.

Демо-мозаика намеренно декоративная: она не содержит URL и платёжных данных
и не предназначена для проверки QR-декодера. Реальный код показывается как текст,
не открывает ссылок и не вызывает платежей. Состояние успеха означает только
«QR распознан». Лимитированная демонстрационная анимация не блокирует выход.

Праздничный слой и обычные дудлы подавляются на экране сканера, чтобы не
перекрывать его элементы; на экране перевода остаются подавленными.

При переносе трека A в СберKids слой анимаций должен получать уже существующее
событие распознавания штатного сканера. Браузерное распознавание служит только
для этого прототипа, нового серверного контракта не требуется.

## Файлы

- `web/js/qr.js` — экран, сюжеты, состояния, камера, необязательный звук.
- `web/css/qr.css` — адаптивная вёрстка, варианты оформления и анимации.
- `web/effects/qr/` — собственные SVG для новых сюжетов.
- `web/js/app.js`, `web/index.html` — вход в сканер и переключение экранов.

Нативная оболочка `jury-phone/` не изменялась: камера через её схему
`kids://` не обещается. Браузерное демо проверяется отдельно от нативного приложения.

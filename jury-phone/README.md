# Телефон для жюри

iOS-приложение «Праздники» — оболочка для демо на защите. Внутри та же страница из `web/`, что и на демо-сайте, в режиме `?present=60`:

- раз в минуту меняется праздник или дудл дня, его сцена запускается сама, внизу на 3,5 с появляется подпись;
- жюри может тапать, трясти, наклонять и переворачивать телефон; пока телефон трогали меньше 10 с назад, смена ждёт;
- работает без интернета: `web/` вшита в приложение;
- экран не гаснет, панели отладки и адресной строки нет.

Эффекты здесь не дублируются: в Swift только окно браузера, датчики и вибрация. Правки в `web/` попадают в приложение при следующей сборке.

## Установка на iPhone (один раз, заранее)

1. Mac: Xcode → Settings → Accounts → «+» → Apple ID. Подойдёт обычный бесплатный.
2. iPhone по кабелю к Mac, на телефоне «Доверять этому компьютеру».
3. iPhone: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить, телефон перезагрузится.
4. Открыть `jury-phone/JuryPhone.xcodeproj`. Target JuryPhone → Signing & Capabilities → Team: свой Apple ID (Personal Team). Если Xcode ругается на Bundle Identifier, поменять `com.screensaver.juryphone` на любой свой, например `com.<фамилия>.juryphone`.
5. Вверху выбрать iPhone как устройство и нажать ▶ (Cmd+R).
6. При первом запуске iPhone скажет «Ненадёжный разработчик»: Настройки → Основные → VPN и управление устройством → свой Apple ID → Доверять.

Приложение с бесплатным Apple ID работает 7 дней — ставим накануне защиты или утром.

## Перед тем как отдать телефон

- Включить «Гид-доступ», чтобы жюри не вышло из приложения: Настройки → Универсальный доступ → Гид-доступ. В приложении трижды нажать боковую кнопку → «Начать».
- Режим «Не беспокоить», чтобы уведомления не перекрывали экран.
- Яркость повыше, звук не нужен.

## Как это устроено

| Файл | Что делает |
| --- | --- |
| `JuryPhoneApp.swift` | Запуск, интервал смены (`rotationSeconds`, сейчас 60), экран не гаснет |
| `WebShell.swift` | WKWebView на весь экран. Датчики CoreMotion уходят в страницу обычными событиями `deviceorientation` и `devicemotion`, поэтому JS-код тряски, ветра и переворота тот же, что в браузере. Системный жест «встряхнуть» — запасной путь к тряске. `VIBRATION_EVENT` из страницы → тактильный отклик |
| `BundleSchemeHandler.swift` | Отдаёт файлы `web/` по адресам `kids://app/...`, как сервер: `fetch()` конфигов и картинок работает офлайн |

Смена эффектов — это `web/js/present.js`. Его можно посмотреть и в браузере: http://127.0.0.1:8765/?present=15 (каждые 15 с).

## Что проверено

- Сборка без ошибок и предупреждений (Xcode 27, iOS 15+).
- Симулятор iPhone 17: страница грузится из приложения без сети, конфиги и SVG подтягиваются, идёт смена эффектов, отладки не видно. Жест «встряхнуть» запускает эффект заново.

На реальном iPhone ещё не проверяли: датчики CoreMotion (наклон, тряска, переворот), вибрацию и плавность. Симулятор датчиков не имеет — это первое, что надо проверить после установки.

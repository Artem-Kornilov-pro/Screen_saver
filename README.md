# Screen Saver — праздничный слой поверх приложения

Хакатон Сбер × НИУ ВШЭ «Создаем эмоции», трек A «Приколы». Код сдаём до 15:00 18 октября.

Когда ребёнок открывает приложение, поверх экрана идёт праздничная анимация: снег, ёлка и гирлянда на Новый год, дальше листопад, весна и т. д. Наклон телефона сдувает частицы ветром, по тапу они лопаются, тряска запускает эффект заново. Что и когда показывать, решает JSON-конфиг, поэтому новый праздник добавляется без релиза. Кнопки приложения при этом всегда нажимаются: слой не перехватывает касания.

План, разбор ТЗ и критерии оценки лежат в [docs/plan.md](docs/plan.md).

## Как запустить

```sh
cd web
python3 -m http.server 8765
```

Открыть http://127.0.0.1:8765/?date=2026-12-31 — эффект запустится сразу.

- Без `?date=` эффект показывается только в даты из конфига (Новый год: 20 декабря – 10 января). В другие дни сама открывается панель отладки с подменённой датой: нажмите «Показать (как тряска)».
- Шестерёнка внизу слева открывает и закрывает панель отладки: подмена даты, ползунок ветра для ноутбука, сброс лимита «раз в день».
- `index.html` можно открыть и двойным кликом. Тогда `config.json` не загрузится (браузер не даёт `fetch` по `file://`), и подставится встроенная копия конфига.
- На телефоне: компьютер и телефон в одной сети, на компьютере `python3 -m http.server 8765 --bind 0.0.0.0`, в браузере телефона `http://<ip-компьютера>:8765/?date=2026-12-31`.

## Структура

```
web/
  index.html            макет приложения + <canvas> слоя + панель отладки
  css/app.css           стили макета и слоя
  js/seasonal.js        праздничный слой: конфиг, выбор эффекта, физика, отрисовка, датчики, тапы
  js/app.js             макет: переходы между экранами, тосты, панель отладки
  effects/config.json   какие эффекты, когда и с какими параметрами
docs/
  plan.md               план на хакатон, разбор ТЗ, риски, сценарий демо
```

## Как это работает

1. `app.js` вызывает `Seasonal.init()`. Слой грузит `effects/config.json`. Если файл битый или недоступен, берёт кэш из `localStorage`, а если нет и его — встроенную копию `FALLBACK_CONFIG` в `seasonal.js`.
2. Через 400 мс после первого кадра срабатывает триггер `first_open_of_day`. Слой ищет эффект, у которого дата попадает в диапазон и есть такой триггер. Из подходящих побеждает самый большой `priority`. Показ запоминается, и в тот же день при входе эффект больше не идёт.
3. Тряска (`devicemotion`, порог 18 м/с²) даёт триггер `shake`, лимита у него нет.
4. Показ длится `durationMs`: 0,6 с появление, частицы падают, последние 1,5 с слой гаснет. Цикл `requestAnimationFrame` работает только во время показа.
5. `<canvas>` лежит поверх экрана с `pointer-events: none`. Тапы слушаются на `document` в фазе захвата с `passive: true`. Слой смотрит, не попал ли тап в снежинку или ёлку, но событие не отменяет, поэтому кнопка под снежинкой тоже нажимается.
6. На лопание слой отправляет `window.postMessage({ type: 'VIBRATION_EVENT' }, '*')` — это канал тактильного отклика из контракта ТЗ.
7. Экраны оплаты, перевода, реквизитов и лимитов вызывают `Seasonal.setSuppressed(true)`. Слой гаснет за 200 мс и не запускается, пока экран открыт.

### API слоя (`window.Seasonal`)

| Метод | Что делает |
| --- | --- |
| `init({ host, canvas, dateOverride, onChange })` | Запускает слой. Возвращает Promise с результатом первого триггера |
| `trigger(name)` | `'first_open_of_day'` или `'shake'`. Возвращает `{ effect, reason }`: что показали или почему нет |
| `setSuppressed(bool)` | Критичный экран: погасить и не запускать |
| `setDateOverride(date \| null)` | Подменить дату (демо). С подменённой датой лимит «раз в день» не действует |
| `setManualTilt(-1…1)` | Ветер вручную, когда нет датчика наклона |
| `resetDailyLimit()` | Сбросить «раз в день» |

## Формат конфига

```json
{
  "version": 1,
  "maxParticles": 80,
  "effects": [
    {
      "id": "new_year",
      "title": "Новый год",
      "dates": { "from": "12-20", "to": "01-10" },
      "priority": 100,
      "triggers": ["first_open_of_day", "shake"],
      "durationMs": 9000,
      "particles": {
        "kind": "snowflake", "count": 60, "speed": [45, 110], "size": [12, 30],
        "colors": ["#8EC5FF", "#B6DAFF", "#6FAEF0"],
        "spin": true, "tiltWind": true, "tapToPop": true
      },
      "decor": [
        { "kind": "tree", "anchor": "bottom_end", "widthPct": 0.34 },
        { "kind": "garland", "anchor": "top" }
      ]
    }
  ]
}
```

| Поле | Значение |
| --- | --- |
| `version` | Должно быть `1`, иначе конфиг игнорируется |
| `maxParticles` | Общий потолок частиц (по умолчанию 80, максимум 200) |
| `dates.from`, `dates.to` | `"MM-dd"`. Диапазон может переходить через Новый год |
| `priority` | Кто побеждает, если в один день подходят несколько эффектов |
| `triggers` | `first_open_of_day`, `shake` |
| `durationMs` | Длительность показа, минимум 2000 |
| `particles.kind` | Пока поддерживается только `snowflake` |
| `particles.speed`, `particles.size` | `[мин, макс]` в px/с и px. Крупные частицы падают быстрее, так получается глубина |
| `particles.colors` | `#RRGGBB`, неверные значения отбрасываются |
| `spin`, `tiltWind`, `tapToPop` | Вращение, ветер от наклона, лопание по тапу |
| `decor[].kind` | `tree` (`anchor`: `bottom_end` или `bottom_start`, `widthPct` 0.15–0.5), `garland` |

Эффект с ошибкой (неизвестный `kind`, кривая дата) выкидывается, остальные работают. Если не осталось ни одного, приложение просто остаётся без эффекта.

## Как добавить эффект

- **Новый праздник на снежинках** (другие даты, цвета, количество): только правка `effects/config.json`, код трогать не нужно.
- **Новые частицы** (листья, лепестки): в `seasonal.js` добавить вид в `SUPPORTED_PARTICLES` и функцию отрисовки спрайта по образцу `snowflakeSprite`, затем выбирать спрайт по `particles.kind` в `draw()`. Физика общая.
- **Новый декор**: функция отрисовки по образцу `drawTree` или `drawGarland` и вызов в `draw()` по `decor[].kind`. Если декор реагирует на тап, добавить попадание в `onPointerDown`.

Встроенную копию `FALLBACK_CONFIG` в `seasonal.js` держим в синхроне с `effects/config.json`.

## Правила, которые нельзя нарушать (из ТЗ)

- Только чистые HTML, CSS и JS. Никаких библиотек и фреймворков, ни с CDN, ни своей копией.
- Никаких запросов наружу: внешние API, шрифты, аналитика, iframe. Пути между файлами только относительные.
- Слой не блокирует ввод. После любых изменений проверить: во время снегопада ставится галочка в «Моих делах» и нажимается «Перевести».
- На экранах оплаты, перевода, реквизитов и лимитов эффекта нет.
- Запуск приложения не замедляется: конфиг грузится в фоне, первый показ через 400 мс после первого кадра.
- Контент 0+/6+: без брендов, поп-культуры и персонажей, только природа и предметы.
- Пустой или битый конфиг ничего не ломает.

## Что проверено

Проверяли 16 октября в Chromium с экраном 390×844:

- эффект запускается по `?date=2026-12-31` и при повторной загрузке;
- без даты открывается панель, кнопка «Показать» запускает эффект;
- во время снегопада галочка в «Моих делах» ставится, тап по ёлке срабатывает;
- на экране «Перевод» слой гаснет, тряска там не запускает эффект;
- с битым `config.json` страница работает и берёт встроенную копию.

На реальном телефоне ещё не проверяли: плавность 60 FPS, тряску, наклон и запрос разрешения на датчики в iOS Safari.

## Решения

- **16 октября: только HTML, CSS и JS.** Решение команды. Начинали с нативной iOS-песочницы организаторов, но от неё отказались. На защите нужно объяснить, как слой встраивается в нативное приложение: прозрачным WebView поверх экрана или переносом логики на нативный Canvas. Конфиг и правила при этом остаются те же.
- **Лимит «раз в день» только для входа.** Тряска запускает эффект всегда, иначе прикол будет одноразовым, а за это ТЗ снимает баллы.
- **С подменённой датой лимит не действует.** Иначе на демо эффект нельзя показать дважды.

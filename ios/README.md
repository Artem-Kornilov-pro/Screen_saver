# СберKids — нативное iOS-демо

Откройте `SberKids.xcodeproj`, выберите схему **SberKids**, симулятор iPhone и нажмите **Run** (⌘R).

Для своего iPhone выберите устройство и собственную команду в **Signing & Capabilities**. Apple ID и подпись в этом проекте не настраивались. Камера и реальные наклоны/перевороты проверяются на iPhone; симулятор показывает явно обозначенное QR-демо.

В приложении: QR → «Поймать демо-код»; выбор сюжета и рамки — сверху/снизу; кнопка ⓘ — стили, повтор и ошибка. Шестерёнка на главном экране открывает список 19 активных дудлов (25 записей в манифесте), сезоны, события и настройки. Для комбо: тап по стикеру → три быстрых тапа (либо обводка) → указанный финальный жест. Переводы — макет без реальных денег.

Swift 6, SwiftUI, iOS 15.0+. Системные AVFoundation, CoreMotion, Canvas; сторонних runtime-зависимостей и WebView нет. Эталон — тёмный `Screen_saver/web` на коммите `006abd5`; исходная веб-копия не менялась. Светлый Figma не используется: пользователь подтвердил тёмный эталон.

Проверено: Xcode 27.1 / Swift 6.4, симулятор iPhone 16 Pro / iOS 18.6; 13 модульных и UI-тесты; прежняя матрица всех 25 QR-сочетаний сохранена, включая все 25 QR-сочетаний. Сверка с обновлённым main описана в `Reports/MainSync.md`. Результаты: `Reports/Validation.xcresult`, логи — `Reports/`.

Не подтверждено: живое сканирование/датчики и стабильные 60 FPS на физическом устройстве; запуск на iOS 15 (runtime отсутствует); совпадение каждого кадра в пределах 2 pt / 50 мс. Ресурсы после офлайн-конвертации — около 1.10 МБ PNG; это не размер IPA и не измеренный прирост приложения. Лимиты ≤6 МБ контента и ≤3 МБ прироста требуют сравнения одинаковых Release-сборок с/без слоя.

## Конфигурация

Встроенный набор → последний проверенный кэш → HTTPS JSON с CDN. URL указывается в демопанели; автоматически сетевые запросы не выполняются. Фикстуры A/B, битый JSON, несовместимая схема и отсутствующий ресурс находятся в `SberKids/Resources/Content`. A/B — локальные сценарии, не доказательство сетевого обновления.

Нативный конверт: `schema: 1`, `revision`, `doodles` (исходный манифест, объединение по ID), `seasonal` (исходный конфиг), `native.enabled`, `native.qrThemes`, `native.qrFrames`. QR-ключи — дополнение нативной схемы, в веб-конфиге их нет. Новые ресурсы — `assets: [{id, url, sha256}]`: PNG ≤2048×2048, тот же HTTPS-хост, ≤64 файла, кэш ≤6 МиБ. JSON ≤2 МиБ. SVG на устройстве не исполняется; новые типы рендера требуют релиза.

## Повторная проверка

```sh
xcodebuild -project SberKids.xcodeproj -scheme SberKids -configuration Debug -destination 'platform=iOS Simulator,name=iPhone 16 Pro iOS 18.6' test CODE_SIGNING_ALLOWED=NO
```

Скрипты конвертации используют установленный на этом Mac build-time `sharp`; в приложение он не включается. `Scripts/generate-project.py` воспроизводит проект без XcodeGen. Коммит/пуш не выполнялись; `ios` — отдельный локальный Git-репозиторий, ветка `feat/ios-native`.
